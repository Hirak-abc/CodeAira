# CodeAira — Competitive Coding Assessment Platform

**CodeAira** is a LeetCode-inspired coding assessment platform designed to evaluate a user's **problem-solving ability, coding consistency, and integrity** under controlled assessment conditions.

Unlike traditional coding platforms, CodeAira introduces **anti-cheating and assessment restrictions** to simulate a real coding test or examination environment.

## 🚀 Key Features

* **Coding Challenges** — Solve programming problems across different difficulty levels and topics.
* **Full-Screen Assessment Mode** — Users are required to remain in full-screen mode while attempting an assessment.
* **Anti-Copy/Paste Protection** — Copying, pasting, and other shortcuts that could facilitate cheating are restricted.
* **Cheating Detection** — Attempts to exit full-screen mode, bypass restrictions, or violate assessment rules are detected.
* **Dynamic Scoring** — Users earn points based on their coding activity and successful problem-solving.
* **Penalty System** — Violating assessment rules or skipping a question can result in score deductions.
* **Self-Assessment** — Users can measure their coding performance under conditions similar to technical interviews and coding examinations.
* **Progress Tracking** — Track scores, solved problems, attempts, and overall coding performance.
* **Timed Assessments** — Complete coding challenges within a defined time limit.
* **Code Execution & Evaluation** — Submitted solutions are tested against predefined test cases.

## 🎯 Objective

The goal of CodeAira is to provide a **fair and controlled environment for coding assessments** where users cannot simply rely on external resources or copy-paste solutions.

The platform focuses not only on whether a user gets the correct answer, but also on **how they approach and complete coding problems under assessment conditions**.

## 🧠 Scoring System

The platform uses a combination of **positive and negative scoring**.

Users can gain points by:

* Writing and completing code
* Successfully solving problems
* Completing assessments within the given rules

Points may be deducted for:

* Exiting full-screen mode
* Attempting to bypass assessment restrictions
* Skipping questions without completing them
* Other detected violations of assessment rules

This creates a scoring system that rewards both **coding performance and assessment integrity**.
